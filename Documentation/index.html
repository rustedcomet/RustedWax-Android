RustedWax

Android scrobbling for Hive.

RustedWax watches what you actually play in YouTube, YouTube Music, Brave, and Chrome, then writes verified listens to the Hive blockchain.

Download v0.11.2 Setup overview View on GitHub

What it does

A transparent listening history you control, backed by public Hive transactions.

Works across YouTube

Supports the native YouTube and YouTube Music apps plus YouTube playback in Brave and Chrome.

Only logs verified listens

Playback is measured and the video is identified before anything is allowed onto the chain.

Explains recorded outcomes

History shows successful or accepted operations and transaction IDs. Not logged explains recorded refusals; Android can miss playback observations.

Keeps your key on your phone

Your posting key is protected by Android Keystore; transactions are signed locally.

Install

RustedWax v0.11.2 is available as a signed APK from the public GitHub Release.

  1. Download the release Open the latest GitHub Release and download rustedwax-v0.11.2-release.apk.
  2. Install on Android Open the APK. Android may ask you to allow installs from that browser or file manager.
  3. Complete setup Grant Notification Access, add your Hive posting key, and enable only the optional access you need.

Use only a Hive posting key—never an active key, owner key, or master password. Transactions are signed locally on the Android device. Read the complete setup guide.
